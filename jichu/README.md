# 量化信息决策系统（桌面版）

本项目是一个 A 股量化分析工具，核心是一套**同花顺 PC 风格的可视化桌面应用**（`app.py`）。全部使用免费数据源，无需付费 token。

## 快速开始

```bash
python -m venv .venv
.venv\Scripts\activate            # Windows
pip install -r requirements.txt
python app.py                      # 启动桌面版
```

也可以直接双击项目根目录或桌面的 **`启动量化系统.bat`** 一键启动。

> 环境：Python 3.10+（本机已验证 3.11）。GUI 依赖 PySide6、pyqtgraph。

---

## 界面与启动体验

- **窗口自适应居中**：启动时读取当前屏幕可用区域（扣除任务栏），按 92%×88% 估算窗口尺寸并居中；小屏（1366×768）自动收缩到可用区域内，**最大化/最小化/关闭按钮始终可见，无需拖动窗口**。
- **高 DPI 兼容**：统一 `PassThrough` 缩放策略，避免 125%/150% 缩放下布局溢出。
- **分组布局**：六个功能页统一 16px 外边距、12px 分组间距，工具栏/内容/明细以卡片分隔；左右导航 + 顶部状态条 + 底部状态栏。
- **切换过渡**：页面切换使用 220ms 淡入动画；顶部标题与状态栏提示同步更新。
- **信息展示**：红涨绿跌语义色、字号层级（标题/正文/提示）、数值列右对齐、涨跌幅与状态分色、长列表固定表头可滚动可排序。
- **加载反馈**：启动先渲染本地快照（秒开），再由后台线程流式填充各区块；表格加载中显示骨架占位行，配合不确定进度条，不会空白或卡死。

## 六大功能模块

程序启动后，**自动刷新最新市场信息**（涨停、热点、新闻、指数），所有耗时操作均在后台线程执行，界面不卡顿。左侧导航顺序与下文编号一致。

### 1. 信息抓取

- **大盘指数**：上证、深证、创业板、科创50、北证50 实时点位与涨跌幅（盘中每 60 秒自动刷新）。
- **今日涨停池**：涨停个股、连板数、封板资金、首次/最后封板时间、炸板次数、所属行业。
- **涨停原因**：通过东财 F10 核心题材接口，给出每只涨停股的行业、概念题材及具体理由（当日磁盘缓存，跨页面共享）。
- **热点概念**：对当日涨停股的概念做频次聚类，得出当日最强题材。
- **行业/概念板块**：东财细分行业（约 100 个）与概念板块（约 79 个）的涨幅、成交额、领涨股。
- **财经新闻**：四源并发直连 —— **财联社电报 + 东财全球快讯 + 同花顺快讯 + 新浪 7×24**，任一源失败自动跳过，akshare 仅作兜底；按「政策政治 / 宏观经济 / 行业产业 / 公司公告 / 国际地缘 / 网络舆情」分类，并做利好/利空情绪打分。
- **情绪温度**：综合涨停/跌停、连板高度、炸板率、新闻情绪，给出 0~100 的市场情绪温度。
- **并发 + 缓存 + 增量渲染**：指数、涨停池、跌停家数、行业板块、概念板块、新闻等 7 类任务并发抓取（线程池 + 信号量限流），每完成一项立即回填界面；单源超时 4~10 秒、重试上限 1 次，失败不影响其他区块；结果写入 `.cache/`，盘中短 TTL、盘后长 TTL。
- **盘中自动刷新**：交易时段（9:10–11:35、12:55–15:05）按 TTL 自动刷新，非交易时段使用缓存并标注数据时间。

### 2. 个股自选

- 输入代码加入自选（自动补全名称），可移除、可刷新，自选列表持久化到 `watchlist.json`。
- 对每只自选股计算 **MA / MACD / RSI / 布林 / 量比 / 动量** 等多指标，给出多空总分。
- 信号分级：**强烈买入 / 买入 / 观望 / 卖出 / 强烈卖出**，并显示置信度与仓位建议。
- 下方列出多头信号、空头信号明细。

> `watchlist.json` 内自带几只示例股票（九牧王、雷科防务、贵州茅台、宁德时代、中芯国际），可自行增删。

### 3. 策略形态选股（日线 + 周线）

- **硬过滤**：市值区间（默认 30~3000 亿）、板块（全部/沪深主板/创业板/科创板/北交所）、股价 3~300 元、成交额 ≥ 0.5 亿，剔除 ST/退市/新股/停牌，按成交额排序取前 N 只候选（200/400/600/800/全部）。
- **日线形态（9 类）**：均线多头排列、均线金叉、放量突破、回调企稳、强势动量、量价齐升、均线粘合、MACD 金叉、缩量回踩 MA20。
- **周线形态（5 类）**：周线多头排列、周线金叉、周线放量、周线突破、周线回调（日线重采样为周线计算）。
- **形态分**：按命中标签加权累计（日线权重 6~12，周线权重 6~12），并展示命中数、形态标签、日线/周线分组与逐条命中依据。
- **可运行、可中断**：点击即并发拉取候选日线并实时增量回填表格，支持“停止”按钮（已完成结果保留）；结果按任意列排序、可导出 CSV。
- 同时保留原两套严格策略：**趋势信号 31 项**、**回调反转 22 项**，逐条展示当前值与要求值，并附持仓风控规则。

### 4. 开盘前多因子荐股（仅限沪深北）

- **两批定时**：工作日 9:27 自动生成「早盘批」、12:57 生成「午盘批」（均为开盘前，留足反应时间），也可手动生成；每批结果落盘到 `.cache/picks_{morning|noon}_日期.json`，重启自动回填。
- **八因子百分制打分（合计 100）**：趋势 15、量价 12、流动性 8、板块轮动 20、龙头地位 15、题材热度 12、资金流 8、风险 10。
  - 趋势：日线 MA 多头排列、20 日动量、MACD、距 60 日高点位置；
  - 量价：量比、放量突破、量价齐升；
  - 流动性：成交额、换手率适中区间（过滤过低与过热）；
  - 轮动：板块当日涨幅、5 日动量、所处升温/加速/退潮阶段；
  - 龙头：连板身位、封单额、行业涨停家数与行业领涨；
  - 题材：东财 F10 核心题材与当日热点概念、利好新闻的匹配度；
  - 资金：主力净流入/成交额占比、封单强度；
  - 风险：ST/退市/停牌/新股/异常波动/高位巨量等扣分项。
- **硬性风险剔除**：ST/退、新股、停牌、成交额 < 0.8 亿、换手 > 35%、市值 < 20 亿或 > 5000 亿直接排除；同一行业最多 3 只，避免单板块霸榜。
- **可解释输出**：每只票给出综合分、8 项因子分与各自说明（如“MA5/10/20 多头”“所属行业当日 +2.1%，处于加速阶段”）、风险等级与命中概念，选中行即可查看完整打分构成。
- **数据降级**：快照缺失时先读本地缓存再抓取；行情失败用缓存；日线不可用时按行情快照估算因子并在界面标注「数据降级」，保证非交易时段也能稳定产出。

### 5. 机构策略学习库（公开信息 + 近似实现）

> **重要声明**：幻方、九坤、明汯、灵均等机构的真实因子公式、权重、持仓从未公开。本模块只整理**官方公开信息**与**媒体分析（明确标注未证实）**，再把方法论映射到本系统已有的 8 个可计算因子，做可运行的近似选股。**公开资料 ≠ 机构真实策略，结果不构成投资建议。**

- **左侧策略列表**：幻方、九坤、明汯、灵均、WorldQuant Alpha101、经典多因子 6 套框架。
- **右侧学习面板**：每套策略分「一句话 / 公开事实（可核实） / 媒体推断（未证实） / 映射到本系统 8 因子及权重 / 数据要求 / 风险与局限 / 参考来源（可点击）」。
- **一键套用**：选择策略并设置取前 N 只，后台调用多因子引擎按该策略权重重分配因子满分，输出真实名单；结果可排序、可导出 CSV，选中个股可查看因子构成与命中理由。
- **权重实现**：保持每个因子「原始得分 / 原始满分」的比例不变，按目标权重换算满分（例如幻方近似的趋势 20、量价 18、流动性 10、轮动 8、龙头 8、题材 8、资金 12、风险 16，合计 100），因此因子内部强弱不被扭曲，只改变总分构成。

### 6. 量化回测（双模式）

两种模式共用第五模块的 6 套策略权重与同一套 8 因子（趋势、量价、流动性、板块轮动、龙头地位、题材热度、资金流、风险）。**收盘后生成信号、次日开盘成交，不使用未来数据**；佣金万三、印花税千一、滑点 0.1% 均计入费用。

- **通用参数**：模式、策略（幻方/九坤/明汯/灵均/WorldQuant/经典多因子）、回测长度（默认 **18 个月**，可改 3~60）、初始资金（默认 **20 万**）。
- **模式一 · 单一个股（择时）**：自选 6 位代码（下拉可搜索，也可直接输入）。逐日计算 8 因子综合分，综合分达到进入阈值时次日开盘买入，**仓位随综合分在 50%~100% 之间变化**；跌破退出阈值、8% 固定止损、13% 移动止损、MA20 破位或持有超过 120 天则卖出。
  - 输出：`每日操作`表逐日列出 **仓位%、买卖价格、成交数量、现金、总资产、操作原因**；`交易明细`表列出每笔买卖的方向、价格、数量、金额、仓位、买入日期/买入价、盈亏与原因。
- **模式二 · 全市场组合（多因子）**：当日全市场快照先剔除 ST/退市/新股/停牌、价格 < 2 元、成交额 < 2000 万，再按成交额与流通市值排序取**流动性前 N 只**（界面可设股票池上限，默认 400）。每 5/10/20 个交易日（默认 20）做一次横截面百分位打分，选前 N 只（默认持仓 10 只），按策略行业上限分散，**等权调仓**，单票 8% 止损。
  - 基准为同一股票池的等权买入持有，因此「超额收益」反映的是选股与调仓能力，而不是市场整体涨跌。
  - 输出：每日组合仓位、现金、总资产、持仓只数与调仓说明；交易明细含每笔调仓的价格、数量、金额、目标仓位、盈亏与原因。
- **绩效指标卡**：总收益、年化、超额、最大回撤、夏普、胜率、盈亏比、平仓次数。
- **图表（三行）**：归一化净值（策略 vs 基准）、回撤 %、仓位 %。
- **可中断**：全市场模式需并发拉取股票池日线，运行中可随时点「停止」，界面不阻塞。

> **回溯说明**：历史新闻与公告无法按日回溯，因此「信息面」用行业动量、量价结构、相对强弱等可复现指标代理，避免引入未来函数。全市场模式受免费数据源限制，实际是「流动性前 N」而非严格 3,000+ 只全市场，且以当日快照筛选存在幸存者偏差。趋势型策略胜率通常偏低，应结合盈亏比与超额收益一起看。

## 数据源与降级顺序（全部免费）

程序按以下优先级自动降级，单源失败不会阻塞整体；所有请求均设置短超时与有限重试。

| 数据 | 优先级（→ 表示失败后切换下一源） |
| --- | --- |
| 全市场实时行情 | 东财 `clist`（分页并发，字段含市值/换手/行业）→ 腾讯 `qt.gtimg.cn`（50 只/批并发）→ 本地缓存 |
| 股票代码表 | 本地缓存 → akshare（仅兜底，避免启动被 30 秒首包拖慢） |
| 日 K 线 | 新浪 `getKLineData` → 腾讯 → 东财 → akshare → 湘财 → 银河（`fast` 模式不含 akshare） |
| 大盘指数 | 新浪 `hq.sinajs.cn` → 东财 `ulist.np/get` |
| 涨停池 | 东财 `push2ex`（并发最近 3 个交易日，取最新有数据日）→ akshare 兜底 |
| 跌停家数 | 东财跌停池（并发最近 3 日，按日期新→旧取第一个有效值） |
| 涨停原因/题材 | 东财 F10 `RPT_F10_CORETHEME_BOARDTYPE`（过滤指数成分/统计标签等噪音） |
| 行业/概念板块 | 东财 `clist` 分页（`m:90+t:2` / `m:90+t:3`）→ 新浪 49 行业 |
| 板块轮动 | 东财板块涨幅/成交额 + 近 5 日涨停行业聚类（`fetch_zt_history`） |
| 财经新闻 | 财联社电报 → 东财全球快讯 → 同花顺快讯 → 新浪 7×24 → akshare 兜底（并发 + 标题去重） |
| 5 分钟 K 线 | baostock（前复权，仅回测/分钟场景） |

**缓存策略**（`.cache/`，原子写入）：

| 文件 | 内容 | 有效期 |
| --- | --- | --- |
| `latest_snapshot.json` | 完整信息快照（启动先显后刷新） | 永久保留，按生成时间标注 |
| `quotes_日期.json` | 全市场行情 | 盘中 120 秒 / 非盘中 900 秒 |
| `kline_代码_日期.json` | 日线（新浪/腾讯/东财） | 盘中 25 分钟 / 盘后 12 小时 |
| `coretheme_代码_日期.json` | F10 核心题材 | 7 天 |
| `picks_批次_日期.json` | 荐股批次结果 | 按日期留档 |
| `watch_signals.json` | 自选信号 | 短 TTL |

> 交易时段判断：工作日 09:10–11:35、12:55–15:05；非交易时段自动延长缓存有效期，减少重复请求。

## 已知限制

- 所有数据来自公开免费接口（东财/同花顺/财联社/新浪/腾讯/湘财/银河），**接口改版或反爬策略变化时对应源可能失效**；程序会跳过失败源并降级，但极端情况下该区块可能显示缓存或空。
- 首次冷启动全市场行情需逐页拉取（约 10~15 秒），之后依赖缓存可秒开；形态选股“全部”模式需逐只拉日线，耗时随候选数线性增长，建议按需选择 200~600 只。
- 周线形态由日线重采样（`W-FRI`）计算，新股/停牌导致周数不足 20 时周线标签为空。
- 多因子荐股中“资金流/主力净流入”为公开行情与封单推算的近似值，并非交易所逐笔资金流；风险因子为规则打分，不能替代基本面与合规判断。
- 非交易时段价格为最近收盘价，盘中异动无法提前反映；开盘前批量生成依赖前一交易日的数据与当日早间新闻，9:27 前新闻可能尚未完全发布。
- 回测为收盘生成信号、次日开盘成交的近似撮合，已计入佣金万三、印花税千一与 0.1% 滑点，但未模拟涨跌停无法成交、停牌撮合与冲击成本，结果仅供策略方向参考。
- 全市场模式受免费接口与本地算力限制，股票池为「流动性前 N」（默认 400），并非严格意义上的全市场，且以当日快照筛选存在幸存者偏差；股票池越大，首次拉取日线越慢。
- 历史新闻/公告无法按日回溯，回测中的「信息面」由行业动量、量价与相对强弱代理，因此回测结果与盘中实时新闻驱动的实盘表现可能存在差异。
- **机构策略学习库中的权重为公开方法论映射后的经验值，不是机构真实参数**；本系统没有财务/逐笔/高频数据，无法实现价值质量因子、日内 T0 与指数对冲，因此不能复现任何机构的真实业绩。
- 策略套用复用多因子引擎的同一套数据与降级逻辑：冷启动首次运行仍需拉取全市场行情与候选日线（约 10~40 秒，取决于候选数与网络），之后依赖 `.cache/` 明显加快。
